# Планировщик задач (Todo Scheduler)

Веб-сервер для управления задачами с поддержкой повторяющихся событий, аутентификации и REST API.

## Описание проекта

Планировщик задач позволяет:
- Создавать, читать, обновлять и удалять задачи
- Настраивать повторение задач (ежедневно, еженедельно, ежемесячно, ежегодно)
- Автоматически рассчитывать следующие даты выполнения
- Искать задачи по дате, названию или комментарию
- Работать через веб-интерфейс или REST API
- Защищать доступ паролем через JWT-аутентификацию

##  Локальный запуск

### Предварительные требования
- Go 1.25
- SQLite 

### Шаги запуска:

1. Клонируйте репозиторий:
   ```bash
   git clone <url репозитория>
   cd project/cmd
   ```

2. Создайте файл .env в корне проекта:
   ```bash
   PORT=7540
   TODO_DBFILE=../scheduler.db
   APP_ENV=dev
   TODO_PASSWORD=12345
   ```
3. Установите зависимости:
   ```bash
   go mod download
   ```

4. Запустите сервер:
   ```bash
   cd cmd
   go run main.go

   (Обязательно запускать из cmd, иначе данные из web не прочтутся)
   ```

5. Откройте в браузере:
   http://localhost:7540


6. Команда для запуска тестов:
   ```
   go test ./tests
   ```
7. Запуск через Docker:
    1) Соберите исполняемый файл:
    ``` 
        go build -o scheduler ./cmd 
    ```
    2) Соберите Docker образ:
    ```
        docker build -t scheduler-app .
    ```
    3) Запуск контейнера:
    ```
        docker run scheduler
    ```

Проверка работы:
1) Откройте браузер: http://localhost:7540
2) Для входа используйте пароль из переменной TODO_PASSWORD


API Эндпоинты:
Без аутентификации:
1)  GET /api/nextdate - расчет следующей даты
2)  POST /api/signin - аутентификация

С аутентификацией:
1)  GET/POST/PUT/DELETE /api/task - работа с одной задачей
2)  GET /api/tasks - получение списка задач
3)  POST /api/task/done - отметка задачи как выполненной


Технологии:
- Backend: Go 1.25
- База данных: SQLite
- Аутентификация: JWT
- Логирование: logrus
- Конфигурация: .env файлы (joho/godotenv)
- Контейнеризация: Docker
